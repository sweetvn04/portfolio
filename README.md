# Portfolio - Nguyễn Quốc Bảo

Hi there! This is my personal portfolio website, built to showcase my journey as a **Computer Science** student specializing in **System Administration**, **DevOps**, and **Modern Web Development**.

## 🌐 Live Demo
Check out the live site: [portfolio.sweetvn2004.id.vn](https://portfolio.sweetvn2004.id.vn)

## 🏗️ Architecture & Tech Stack
This project is built using a modern, scalable stack and follows a "Hybrid Deployment" strategy to ensure 24/7 availability while keeping Home Lab projects self-hosted.

- **Frontend:** Next.js 15+ (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS 4, Framer Motion (Animations), Shadcn UI
- **Infrastructure:** Docker, GitHub Actions (CI/CD)
- **Monitoring/Services:** Self-hosted Home Lab (Jellyfin, Nextcloud, Ninja School Servers)

## 🚀 Key Features
- **Auto-fetching Projects:** Uses GitHub API to dynamically showcase my public repositories.
- **AI Integration:** Features my **AI VTuber** project integrated with the Gemini API and Live2D.
- **System Focus:** Highlighting my extensive experience with Linux (Fedora), Docker, and Networking.
- **Contact Form:** Integrated with Formspree for direct communication.

## 🛠️ Performance & DevOps
The project follows a "Continuous Quality" approach:
- **Linting & Type Checking:** Proof of quality code via GitHub Actions.
- **Optimized Deployment:** Hosted on **Vercel** for global performance and uptime.
- **Showcase Docker:** Includes a multi-stage `Dockerfile` and `docker-compose.yml` for technical demonstration.
